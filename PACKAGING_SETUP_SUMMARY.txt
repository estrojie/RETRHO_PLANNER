RHO Planner desktop release packaging
=====================================

Outputs produced by GitHub Actions
----------------------------------
Windows x86-64:
  - RHOPlanner-Windows-x64.exe (single-file convenience build)
  - RHOPlanner-Windows-x64.zip (recommended folder build)

macOS:
  - RHOPlanner-macOS-arm64.dmg and .zip (Apple Silicon)
  - RHOPlanner-macOS-x86_64.dmg and .zip (Intel)

Linux x86-64:
  - RHOPlanner-Linux-x86_64.AppImage
  - RHOPlanner-Linux-x86_64.tar.gz

The Linux executable is built in manylinux_2_28 and smoke-tested in Ubuntu
20.04, Linux Mint 22, and Arch Linux containers. The tarball is a fallback
when AppImage/FUSE is unavailable.

How to use
----------
1. Merge the packaging overlay into the root of the existing GitHub repo.
2. Keep main.py and planner_core.py in the repository root.
3. Commit and push.
4. Run Actions > Build desktop executables for test artifacts.
5. Push a v-prefixed tag (for example v1.0.0) to build and publish a release.

Read PACKAGING.md for complete instructions, limitations, local build commands,
and signing guidance.
